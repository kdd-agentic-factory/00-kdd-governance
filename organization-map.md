# Organigrama y Mapeo de Roles

Estructura organizacional del sistema KDD.

## Estructura General

```
KDD Organization
├── Governance
├── Architecture
├── Operations
└── Development
```

## Roles Principales

### Governance
- Encargados de políticas y decisiones estratégicas
- Supervisión de cumplimiento normativo

### Architecture
- Diseño de soluciones
- Decisiones técnicas arquitectónicas

### Operations
- Gestión operativa del sistema
- Monitoreo y mantenimiento

### Development
- Implementación de agentes y skills
- Desarrollo de funcionalidades

## Responsabilidades Cruzadas

- **Seguridad**: Todos
- **Documentación**: Todos
- **Trazabilidad**: Todos
- **Calidad**: Todos
