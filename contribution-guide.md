# Contribution Guide

Guia de contribucion para el repositorio de gobierno KDD.

## Flujo recomendado

1. Crear o actualizar requisitos.
2. Evaluar viabilidad.
3. Documentar diseno o ADR.
4. Descomponer tareas.
5. Implementar con pruebas.
6. Verificar as-built.
7. Actualizar metricas y trazabilidad.

## Cambios de gobierno

Los cambios en politicas, permisos, seguridad, aprobaciones, Kubernetes, datos o decisiones de carrera requieren revision humana explicita.

## Pull requests

Todo PR debe indicar:

- Artefacto KDD afectado.
- Repositorios impactados.
- Politicas o ADRs relacionados.
- Riesgos.
- Validaciones realizadas.
