# Race Engineering Decision Lifecycle

These are governance process rules, not executable workflows.

```text
Telemetry Evidence
-> Pattern Detection
-> Model Prediction
-> Recommendation
-> Risk Assessment
-> Digital Twin Validation
-> Crew Chief Approval
-> Setup Change
-> Post-Change Evaluation
-> Paper Evidence
```

## Required Controls

- Recommendation must include evidence.
- Risk assessment must classify the decision as informational, advisory, actionable or critical.
- Actionable and critical decisions require crew chief approval.
- Setup changes must produce post-change evaluation.
- Paper evidence must link back to telemetry, model, simulation and approval artifacts.
