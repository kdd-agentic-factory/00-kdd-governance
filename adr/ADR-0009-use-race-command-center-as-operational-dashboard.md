# ADR-0009: Use Race Command Center as Operational Dashboard

- **Estado**: Accepted
- **Fecha**: 2026-05-04

## Contexto

El ecosistema requiere una interfaz operacional para centralizar telemetria, recomendaciones, aprobaciones humanas y evidencia de carrera.

## Decision

Usar `15-race-command-center` como dashboard operacional para decisiones de carrera y supervision del ciclo cerrado.

## Consecuencias

- Las recomendaciones criticas deben quedar auditadas.
- Los cambios de setup requieren trazabilidad y aprobacion segun politica.
- Los resultados relevantes deben generar paper notes cuando apliquen.
