# ADR

Architecture Decision Records for the KDD-governed agentic race engineering platform.

## Function

ADRs document important architecture decisions. They explain why the decision exists, what repositories it affects and how it supports the academic contribution.

## Required Format

Each ADR must follow [templates/adr.template.md](../templates/adr.template.md):

- Status.
- Context.
- Decision.
- Consequences.
- Alternatives Considered.
- Related Repositories.
- Paper Alignment.
