# Ciclo de Vida KDD

Metodología del Knowledge-Driven Development.

## Fases del Ciclo KDD

### 1. Discovery
- Identificación de requisitos
- Recopilación de conocimiento
- Documentación de necesidades

### 2. Design
- Diseño de soluciones
- Arquitectura técnica
- Definición de capacidades

### 3. Development
- Implementación
- Creación de skills
- Desarrollo de agentes

### 4. Validation
- Testing y validación
- Aprobación humana
- Aseguramiento de calidad

### 5. Deployment
- Despliegue a producción
- Monitoreo inicial
- Documentación as-built

### 6. Operations
- Operación y mantenimiento
- Monitoreo continuo
- Mejora iterativa

### 7. Retirement
- Deprecación
- Migración de datos
- Archivado

## Artefactos por Fase

| Fase | Artefactos Principales |
|------|------------------------|
| Discovery | Requirements, Feasibility Study |
| Design | Design Document, ADR |
| Development | Code, Skills, Agents |
| Validation | Test Reports, Approvals |
| Deployment | Release Notes, As-Built |
| Operations | Metrics, Logs, Alerts |
| Retirement | Deprecation Notice, Archive |
