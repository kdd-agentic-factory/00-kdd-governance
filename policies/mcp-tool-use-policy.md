# MCP Tool Use Policy

## Proposito

Regular el uso de herramientas externas mediante MCP.

## Reglas

- Todo uso de herramienta debe estar autorizado por permiso del agente.
- Las herramientas que lean o modifiquen datos sensibles requieren auditoria.
- Las herramientas que ejecuten cambios criticos requieren aprobacion humana.
- La salida de una herramienta debe registrarse cuando soporte una decision.
