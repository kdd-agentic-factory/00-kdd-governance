# Telemetry Data Policy

## Proposito

Regular seleccion, limpieza, transformacion y uso de datos de telemetria.

## Reglas

- Todo dataset debe tener dataset card.
- Las senales deben documentar origen, frecuencia, unidades y calidad.
- Outliers, gaps y correcciones deben registrarse.
- Los datos usados en paper deben ser reproducibles o tener sustituto anonimo equivalente.
